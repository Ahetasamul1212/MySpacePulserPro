**Run Locally**

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (comes with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Ahetasamul1212/MySpacePulserPro.git
cd MySpacePulserPro```

**npm install**
